# Documentation Map

Top-level documentation is grouped by working area:

- `FEATURE_INVENTORY.md` - broad catalog of major and minor module-system features.
- `campaigns/` - campaign arcs, campaign state, branching examples, and campaign implementation notes.
- `combat/` - combat-facing systems, including formation planning.
- `companions/` - companion depth, interactive quests, retinues, QA, and overhaul notes.
- `company/` - company morale, training, surgery, troop dialogue, and internal party systems.
- `edit/` - build doctor allowlists, baselines, and editor-facing maintenance files.
- `economy/` - trade, banking, production, and center economy planning.
- `quests/` - quest architecture, quest design, imported quest audits, and quest-specific planning.
- `reports/` - audits, generated reports, extracted references, and implementation checklists grouped by topic.
- `settlements/` - village, health, raid, and garrison design notes.
- `systems/` - realm/system-level designs such as diplomacy and strategy advisor planning.
- `tooling/` - setup and module-system modernization notes.

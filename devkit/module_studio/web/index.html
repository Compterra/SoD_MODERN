STATIC EVIDENCE

Workspace overview

The Studio reads the same indexes used by MCP and the JSON CLIs. It does not simulate M&B runtime behavior.

How to work safely

  1. Find the exact semantic entity, route, or overlay.
  2. Inspect linked context, graph edges, and static hazards.
  3. Generate a semantic patch plan and review its unified diff.
  4. Rehearse with a dry-run. A real source apply requires the plan SHA and an explicit confirmation.
  5. Use the normal reviewed build and target in-game smoke path afterward.

Evidence boundary

Static tools can make the surprise smaller: source ownership, generated provenance, direct links, string/register risk, first-match dialogue shadows, and likely layout conflicts. Dynamic state, engine execution, and final screen behavior remain in-game checks.
